Architecture & Native Android Integration

This directory contains both this interactive web simulator and a complete, production-ready native Android AppWidget written in Kotlin using modern Jetpack Architecture components.

1. REST API Endpoint

The widget queries the Migoku API endpoint:

GET /api/v1/status/counts?lang=ja Header: X-Api-Key: <API_KEY>

Returns:

[ { "known_count": 1420, "learning_count": 85, "unknown_count": 280, "ignored_count": 30 } ]

2. Native Android Codebase Included

  • MigokuWidgetProvider.kt: Extends AppWidgetProvider and handles broadcast updates and manual tap-to-refresh.
  • MigokuWidgetWorker.kt: Background CoroutineWorker using Jetpack WorkManager for battery-efficient background updates.
  • MigokuApiClient.kt: Queries the Migoku REST API and downloads/caches the Migaku GitHub avatar bitmap from https://avatars.githubusercontent.com/u/52677511?s=200&v=4.
  • WidgetConfigActivity.kt: Native configuration activity allowing the user to configure Server URL and API Key upon placing the widget.

3. Building the Native APK

cd examples/android-widget ./gradlew assembleDebug
