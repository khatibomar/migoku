# AGENTS.md

## Commands

- Build: `make build` (`go build -o bin/migoku`); broad compile check: `go build ./...`
- Run dev server: `make run` (runs `LOG_LEVEL=debug API_SECRET="top-secret" go run .`)
- Lint (matches CI): `make lint` (`golangci-lint run --config .golangci.yml`); CI installs golangci-lint v2.9.0. Newer local lint versions can panic on this Go toolchain; pin v2.9.0 for parity.
- Tests: root package has none; run `go test ./examples/discord-nickname/` and `go vet ./...`.
- Docker: `make docker-run` (`docker compose up --build`).
- Static examples: `make examples` (serves `./examples` on :4173).
- Android widget: `ANDROID_HOME=... JAVA_HOME=...` (JDK 17) then `make android-widget-apk`, or `./build-apk.sh [release]` (script is gitignored). **Local builds: always run `./build-apk.sh` with no flags (debug) or `./build-apk.sh release` — it sets JAVA_HOME/ANDROID_HOME correctly.** Local `examples/android-widget/keystore.properties` is gitignored; if it exists pointing to a missing keystore, release builds fail — remove it to use debug key fallback.
- Unikraft: requires buildkitd or Docker; see Makefile targets and README.

Verification order: `go build ./...` -> `go vet ./...` -> `make lint` (v2.9.0) -> `go test ./examples/discord-nickname/`.

## Architecture

- Single Go module `github.com/khatibomar/migoku` with root `package main` as the entire HTTP API.
- `main.go` wires routes: `/`, `/docs`, `/openapi.yaml`, `/auth/*`, `/api/v1/*`, `/dev/*`.
- State is in-memory: `Application.accounts` maps derived API keys to `*MigakuClient`; login creates a client, downloads the Migaku SRS DB to an OS temp dir, and starts a refresh ticker based on `CACHE_TTL`.
- `examples/discord-nickname` shares this module and has its own tests; `examples/android-widget` is a separate Gradle/JDK17 project. Lint excludes the whole `examples` tree (`.golangci.yml` paths).

## Quirks

- `API_SECRET` is required; API keys are HMAC(email, password) keyed by it, so changing the secret invalidates all keys.
- Env: `PORT` (8080), `CORS_ORIGINS` (`*`), `CACHE_TTL` duration string (default `10s`), `LOG_LEVEL` (default `INFO`).
- SQLite is pure Go (`modernc.org/sqlite`); Docker builds with `CGO_ENABLED=0`.
- README endpoints table is generated by CI from `openapi.yaml`; edit the spec, not the table.
- `make clean` removes `./migoku`, not `bin/migoku`; clean binary output with `rm -f bin/migoku`.
- Docker/Compose health checks target `/api/status`, which is not a defined route; the status endpoint is `/dev/status` and requires auth. Fix the healthcheck if debugging container readiness.
- Cache `Get` deletes expired entries while holding only an `RLock`; do not change cache concurrency casually.
